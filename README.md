# Inventory Management System

## Tech stack
- Node.js
- Express.js
- MongoDb atlas
- Mongoose

## Installation

npm install

## Run

npm run dev

## Environment Variables

PORT = 5000

MONGO_URI=your_mongodb_connection_string

##  APIs

POST /products
GET /products
POST /products/purchase
POST /products/restock
POST /products/:products/history
